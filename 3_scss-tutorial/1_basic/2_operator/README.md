# Sass Operators

Stylesheet của bạn cần tính toán? Sass cho phép làm phép tính ngay trong file style — chỉ cần dùng đúng ký hiệu toán học, giống như viết sổ tay tính tiền trên chính tờ CSS.

> Sass cung cấp các toán tử số học chuẩn: `+`, `-`, `*`, `/`, và `%`

Ví von: biến là các con số bạn cất sẵn, còn toán tử là máy tính bỏ túi — lấy số ra, bấm phép tính, kết quả tự chèn vào CSS.
