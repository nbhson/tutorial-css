# CSS3 Transitions

> **🇻🇳 Ghi chú:** Phần này hiện là stub (chỉ có link tham khảo). Ý chính: `transition` cho phép thay đổi giá trị CSS **mượt mà trong khoảng thời gian xác định** — khác `animation` ở chỗ transition cần một "trigger" (thường là `:hover`, `:focus`, đổi class) và chỉ chạy 1 lần. Thuộc tính shorthand: `transition: <property> <duration> <timing-function> <delay>`. Đang chờ bổ sung chi tiết tiếng Việt.
